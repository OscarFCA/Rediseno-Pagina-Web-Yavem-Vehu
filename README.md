# Rediseño Página Web Yavem Vehu

Rediseño del sitio web institucional de **Yabem-Vehu**, empresa de seguridad privada con 15 años de experiencia en CDMX y Estado de México.

## Stack

Sitio estático con React 18 servido vía CDN (UMD) y JSX compilado en el navegador con Babel Standalone. Sin build step.

## Estructura

```
.
├── index.html          # Entry point
├── assets/
│   ├── css/styles.css
│   ├── js/             # components.jsx, pages.jsx, app.jsx
│   ├── img/
│   └── video/
└── uploads/            # Imágenes y media del sitio
```

## Despliegue

Publicado vía **GitHub Pages** desde la rama `main`.
